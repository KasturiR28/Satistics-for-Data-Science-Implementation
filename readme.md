## 🛠️ Technologies Used

- Python
- NumPy
- SciPy
- Jupyter Notebook

---

## 📚 Concepts Covered

### ✅ Statistical Tests

#### Parametric Tests
These tests assume the data follows a normal distribution.

Examples:
- Z-Test
- T-Test
- ANOVA

#### Non-Parametric Tests
These tests do not assume normal distribution.

Example:
- Chi-Square Test

---

## 📊 Implementations in Notebook

### 🔹 One Sample T-Test

A practical example is used to test the claim:
