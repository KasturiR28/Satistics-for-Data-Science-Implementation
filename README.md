# 📊 Statistical Python & Hypothesis Testing Implementation

A beginner-friendly Data Science project demonstrating important **Statistics concepts and Hypothesis Testing techniques using Python**. This repository contains practical implementations of statistical calculations, measures of dispersion, and parametric hypothesis testing using Python libraries like NumPy and SciPy.

This project was created to understand and implement core concepts of **Statistics for Data Science and Machine Learning** using Python.

The repository includes:

* Hypothesis Testing
* Parametric Statistical Tests
* One Sample T-Test

# 📚 Concepts Covered

## ✅ Measures of Central Tendency

### 🔹 Mean

Average value of the dataset.

### 🔹 Median

Middle value of sorted data.

### 🔹 Mode

Most frequently occurring value.

---

## ✅ Measures of Dispersion

### 🔹 Range

Difference between maximum and minimum values.

### 🔹 Variance

Measures spread of data points from the mean.

### 🔹 Standard Deviation

Shows how dispersed data is around the mean.
